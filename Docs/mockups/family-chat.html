٢ — لاعب جديد بلا محادثات ولا أصدقاء: ورقة ترحيب بدل الشاشة الفاضية، وتلميح يشير لأيقونة الأصدقاء

٣ — صفحة الأصدقاء (من الأيقونة): نفس التبويبات القديمة، وزر رسالة بكل صف. السهم يرجّع للدردشة

٤ — اختبار النص الطويل: أسماء ورسائل طويلة جداً وأعداد كبيرة، كل شي بسطر واحد مع «…» و«٩٩+»

٥ — شاشة قصيرة (نسبة تابلت ١٠٨٠×١٤٤٠): القائمة تتمرر، والشريط العلوي والسفلي ثابتين
