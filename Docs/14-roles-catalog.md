# كتالوج الأدوار (للمستقبل) — لا نفقدها

**ليش هالملف:** المالك عنده أدوار أكتر من اللي انبنى. الكود الحالي بيعرف **٤ أدوار بس** (مواطن، مافيا، طبيب، شيخ) وكل واحد مكتوب بدالة ومعالجة خاصة فيه. هالملف بيسجّل اللي طلبه المالك عشان ما ينسى أي جلسة ولا أي حساب. **مش شرط ننفذها هسا**، بس أي قرار بنية لازم يفتح الباب إلها.

## ١) اللي موجود بالكود هسا (٤ أدوار)

| الدور | فريقه | قدرته | ملاحظات |
|---|---|---|---|
| مواطن | المدينة | ولا شي بالليل، صوته نهاراً | |
| مافيا (القاتل) | المافيا | بالليل بيتفقوا على ضحية | بيعرفوا بعض، بيحكوا ليلاً بينهم |
| طبيب | المدينة | بيحمي لاعب كل ليلة (نفسه مرة) | |
| شيخ المواطنين (الشريف) | المدينة | بيفحص لاعب: مافيا أو لأ | الجواب إله وحده |

الفوز: المدينة لما يطلع كل المافيا. المافيا لما يتساوى عددها مع الباقي.

## ٢) اللي طلبه المالك (مش منفّذ)

### أنواع المافيا
1. **مافيا الاستهداف / القاتل** — هو الموجود هسا: بيقتل بالليل.
2. **مافيا المُسكِت** (المالك قال «مافيا الشيخ اللي بسكّت»): بالليل بيختار لاعب **بيسكّته** (ما بيحكي بالنهار التالي). اسم مقترح: **«كاتم الصوت»** (لعب على كاتم الرصاص). أسئلة: مدة الإسكات (نهار واحد؟)، هل بيمنع الدردشة المكتوبة كمان؟ هل بيقدر يصوّت؟ هل بيطلع بالفجر «فلان أُسكت»؟
3. **أنواع مافيا إضافية بالمستقبل** (المالك رح يضيفها): لازم البنية تقبل نوع جديد بدون لمس باقي الأدوار.

### أدوار المواطنين
4. **القنّاص:** بيقنص **مرة وحدة** بالمباراة. إذا كان الهدف **مافيا** ← بيطلع الهدف وبيضل القنّاص باللعبة. إذا كان الهدف **مواطن** ← بيطلعوا **الاتنين** (القنّاص والهدف). أسئلة: متى بيقنص (الليل؟ النهار قبل التصويت؟)، هل بيعلن للكل لما يقنص؟ هل الطبيب بيحمي من القنص؟
5. **المواطن الخفي / «الولد»:** لما **بيموت** (بأي طريقة) **بيختار لاعب بيطلّعه معه**. اسم مقترح بدل «الولد»: **«الفدائي»** أو **«ابن الحارة»** أو **«الوريث»**. أسئلة: بيختار قدام الكل أو سراً؟ لو انطرد بالتصويت أو انقتل ليلاً، الاتنين بيعملوا نفس الشي؟ ليش «خفي» (دوره مخفي عن غيره حتى بعد موته؟).

## ٣) المطلوب من البنية قبل ما نضيف أي دور

الكود الحالي: \`enum Role { Civilian, Mafia, Doctor, Sheriff }\` + دوال خاصة بكل دور (\`MafiaVote\`، \`DoctorSave\`، \`SheriffCheck\`) + رسائل شبكة خاصة (\`mafia\`، \`save\`، \`check\`) + قواعد صوت وأرقام توزيع بالكود. إضافة دور = تعديل بـ٦ أماكن. **مش جاهز للمستقبل.**

المقترح (يتنفذ قبل أول دور جديد، مع اختبارات):
- **تعريف الدور كبيانات** (\`RoleDef\`): الفريق (مدينة/مافيا/محايد)، قدرة الليل (لا شي/قتل/إسكات/حماية/فحص…)، **المحفّزات السلبية** (لما يموت، لما يُطرد)، عدد مرات الاستخدام، شرط الفوز، تأثير الصوت، درجة الخطورة (رصاصات الكرت)، وصف الكرت.
- **خط معالجة الليل:** كل قدرة بتسجّل «نية»، وبتتحلّ بترتيب ثابت (إسكات ← حماية ← قتل/قنص ← فحص) بدل كود خاص بكل دور.
- **رسالة قدرة عامة** (\`act ability <id> <target>\`) بدل رسالة لكل دور.
- **حدث الموت** (\`OnDeath\`) يشغّل محفّزات الأدوار (الفدائي، القنّاص).
- **توزيع الأدوار** من جدول حسب عدد اللاعبين.
- **الواجهة:** الكرت والمشهد والدليل والصوت كلها بتقرا من \`RoleDef\` (الكروت بـ\`Docs/mockups/role-cards.html\`: كل دور له كرت ببورتريه ثابت).
- كل دور جديد = تعريف + اختبارات + سطور سجل + كرت.

## ٤) أسئلة مفتوحة للمالك
1. اسم «مافيا الشيخ اللي بسكّت»: هل نسميه **كاتم الصوت**؟
2. القنّاص: **متى** بيقنص؟ وهل بيعلن؟
3. «الولد/الخفي»: اسم أفضل؟ وهل اختياره علني؟
4. أي دور ننفذه أول: كاتم الصوت أو القنّاص أو الفدائي؟
5. اسم الراوي: «الراوي» ولا «الشيخ»؟ (وانتبهوا: «الشيخ» اسم دور الفاحص).
