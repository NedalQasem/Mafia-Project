# سجل الإصدارات

كل بناء (APK) له رقم إصدار بياخده اسم الملف (`MafiaNight-v1.1.0-dev.apk`) وبيظهر باللعبة: بشاشة الإعدادات («الإصدار»)، وبنسخ التطوير كمان بزاوية كل شاشة (`v1.1.0 dev`). الرقم `رئيسي.ميزة.بناء`: بنزيد **الميزة** لما ينضاف شي جديد، و**البناء** لتصليحات بين الميزات. وبنزيد `AndroidBundleVersionCode` (رقم صحيح) مع كل بناء. تحت: شو فيه كل إصدار، الأحدث فوق.

## 1.1.0 — الغرفة الموحّدة وصوت LiveKit (2026-11-01)
**جديد**
- **شاشة غرفة صوتية جديدة لكل الغرف:** المقعد الكبير للمضيف + مقاعد مايك (٤/٦/٨)، طابور رفع الأيدي (مايك حر أو بالطلب)، دردشة تحت، قائمة الحضور، إعدادات المضيف (قفل، دعوة، عدد المقاعد، دردشة)، وزر «ابدأ المباراة» بغرف المافيا. الطاولة القديمة انحذفت.
- **صوت LiveKit لغرف السهرة** (تجربة): الصوت بيمر بسيرفرنا بدل EOS، بإلغاء صدى وضجيج؛ غرف المافيا بتضل على EOS؛ ولو LiveKit فشل بترجع لـEOS تلقائياً.
- **الإنجليزي:** فحص كامل للشاشات، ترجمة أنماط جديدة، وإصلاح قصّ نصوص طويلة قبل الترجمة (أوصاف الرتب).
- رقم الإصدار ظاهر بالزاوية بنسخ التطوير.

**للتجربة (قسم 37 و38 بخطة الاختبار):** مزامنة المقاعد والدردشة بين لاعبين، وجودة صوت LiveKit بموبايلين.

**بالسيرفر (مش بالـAPK):** الغرف الرسمية، سجل البوتات، توكنات الصوت، LiveKit على الـVPS.
